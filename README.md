### часть про пептиды

Биоактивные пептиды - это короткие цепочки аминокислот длиной 2-50, обладающие специфической биологической активностью:
противораковой, антибактериальной, антиоксидантной, противовоспалительной и другими фармакологически значимыми свойствами.
Такие пептиды крайне полезны для медицинской и пищевой промышленности.

Однако поиск и определение полезных свойств требует значительных временных и финансовых затрат.
Исследование каждого вещества в лаборатории может стоить очень дорого как по времени, так и по ресурсам, поскольку предполагают синтез, очистку и лабораторное тестирование каждого кандидата.

### часть про ИИ в иследовании пептидов

В связи с этим в последние годы активно развиваются вычислительные методы виртуального скрининга, основанные на машинном обучении и QSAR-подходах (Quantitative Structure–Activity Relationship), позволяющие прогнозировать свойства пептидов на основе их структуры до проведения экспериментов.

В настоящее время есть огромное количество готовых решений (https://pubs.rsc.org/en/content/articlehtml/2026/cc/d5cc04998a) основаные на разных подходах:
- Сверточные нейронные сети (CNN) и Рекуррентные нейронные сети (RNN) используются для извлечения признаков из последовательностей аминокислот;
- Графовые нейронные сети (GNN) улавливают сложную трехмерную топологию молекулярных структур;
- Вариационные автокодировщики (VAE) позволяют разрабатывать новые пептиды с заданными свойствами;
- Предобученных языковых моделей (Protein Language Models, PLMs) обеспечивают исключительное понимание молекулярного контекста, достигая самых современных показателей прогнозирования.

### часть про PLM - один из способов решения проблем

Много готовых решений основаны на PLM, такие как ESM и ProtBert, и демонстрируют выдающуюся производительность и точность в различных задачах, связанных с белками и пептидами.

Обучаясь на обширных наборах данных белковых последовательностей, эти модели способны улавливать богатую структурную и функциональную информацию и демонстрируют высокую обобщающую способность.
По сравнению с традиционными подходами машинного обучения, PLM могут автоматически изучать функционально значимые семантические представления и извлекать информативные признаки, называемые эмбеддингами, без необходимости создания дескрипторов вручную.

Примечательно, что прогнозирование на основе эмбеддингов особенно выгодно, когда экспериментальные данные ограничены, предлагая новую и эффективную методологию для прогнозирования и классификации функциональных биоактивных пептидов.

### часть готовые решение основаные на PLM

В **BPFun** (https://link.springer.com/article/10.1186/s12859-025-06190-5) используется пять различных предоставлений данных:
- две PLMs
  - ESM-2
  - ProtT5
- handcrafted features
  - AAindex1
  - one-hot encoding
  - sequences positional encoding

Из каждого предоставлений извлекается признак путем объединения слоев CNN разного масштаба и Bi-LSTM.
Пять признаков объединяются с помощью слоя многоголовочного самовнимания и слоя Bi-LSTM, и, наконец,
используется сигмоидная функция активации для получения прогнозируемых значений различных биоактивных пептидов.

В **BertADP** (https://pmc.ncbi.nlm.nih.gov/articles/PMC12261731) дообучили 4 PLMs (ESM2, ProtT5, Ankh и ProtBert) для бинарной классификации.
Процесс дообучения использовал метод разложения весов на низкоранговые матрицы (DoRA).
Обучение следовало стандартной контролируемой парадигме в течение 10 эпох,
при этом на каждой эпохе фиксировались значения функции потерь на обучении и валидации, а также точность на валидации.
Эпоха с наилучшей точностью на валидации была выбрана как оптимальная модель - это ProtBert.

В **PDeepPP** (https://arxiv.org/abs/2502.15610) для интеграции предварительно обученных знаний со специфическими для
задачи характеристиками разработали гибридную стратегию встраивания, которая динамически объединяет эмбеддинги ESM-2 с пользовательским модулем BaseEmbedding.

PDeepPP использует параллельную архитектуру нейронной сети, которая объединяет сверточные нейронные сети (CNN) и трансформеры.
Модуль TransLinear использует кодировщик трансформеров с полносвязанными слоями, а модуль PosCNN объединяет позиционное кодирование с CNN.

Модули TransLinear и PosCNN обрабатывают последовательности параллельно.
Модуль TransLinear улавливает глобальные зависимости, а модуль PosCNN извлекает локальные закономерности.
Векторы признаков из каждого модуля объединяются для формирования комплексного представления, интегрирующего как глобальную,
так и локальную информацию, которое передается на последующие слои прогнозирования для классификации.

#### часть про feature

**Молекулярные отпечатки (Molecular Fingerprints)** представляют собой компактное числовое описание структуры молекулы,
обычно в виде бинарного или счетного вектора фиксированной длины.
Каждый бит отражает наличие или отсутствие определённого структурного фрагмента или топологического паттерна.

Последнее исследование (https://arxiv.org/html/2501.17901v2 21 Oct 2025) показало, что для коротких пептидов молекулярные отпечатки могут
обеспечивать сопоставимое или более высокое качество предсказаний по сравнению с PLM-эмбеддингами.

Модель MA‐PEP (https://pmc.ncbi.nlm.nih.gov/articles/PMC10966354) предлагает сквозную (end-to-end) глубокую нейросетевую архитектуру,
которая автоматически извлекает смешанные последовательностно-химические признаки пептидов для предсказания антираковых пептидов (ACP).

MA-PEP использует механизм многоголовного самовнимания (multi-head self-attention) для выделения последовательностной информации пептидов.

Кроме того, модуль кодирования химической информации разработан для извлечения информации о химической структуре (Morgan fingerprint) и физико-химических свойствах пептидов (AAIndex).
Механизм перекрестного внимания, применяемый в этом модуле, улучшает захват взаимодействий между этими двумя типами информации.

Для получения единого представление пептидов, используется билинейный механизм внимания (bilinear attention) для
эффективного объединения как последовательностных, так и химических признаков.

### часть про цель данной работы

Целью данной работы является разработка и сравнительный анализ QSAR-моделей для предсказания биоактивности пептидов на основе различных способов представления последовательностей.

Для этого был созданны датасеты из открытых баз данных, такие как https://dbaasp.org/home - курируемая база антимикробных пептидов с экспериментальными характеристиками, http://crdd.osdd.net/raghava/cancerppd/index.php - противораковые пептиды, https://biochemia.uwm.edu.pl/biopep-uwm/ - база биоактивных пептидов.Также взяты датасеты на которых обучались модели, перечисленные выше.

При выборе архитектуру модели бралось в учет, что fingerprints способны уловить локальные признаки, но не контекст, поэтому был добавлен sequence embedding, с последующим объединением признаков.
